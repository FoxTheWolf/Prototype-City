Não precisa ser simulação completa de pacotes: basta uma **chance computada** de pegar os dados de alguma conta de alguém. **Fica para depois das pessoas** (etapa 16: NPCs dentro dos prédios usando a cidade/rede), porque depende de haver gente conectada em volta.
