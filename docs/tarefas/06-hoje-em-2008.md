--- COLE DAQUI ---

Faço um jogo ambientado em **2008**. A tela de carregamento mostra uma curiosidade. Na primeira vez que o jogo abre no dia, ela mostra **"Today in 2008"**: o que aconteceu no mundo **na mesma data (dia e mês) de hoje, só que em 2008**. Nas outras vezes, mostra um fato curioso qualquer sobre 2008. Preciso das duas listas. **Pesquise** (não invente): cada item precisa ser um fato real, com a data certa.

**Regras de cada texto:**
- em **inglês**, uma frase só, **no máximo 150 caracteres**, no presente ou no passado simples, sem emoji;
- interessante para quem joga: tecnologia (celulares, internet, games, computadores, espaço), cultura (filmes, música, TV, livros), ciência, esportes, curiosidades, e os grandes acontecimentos do ano;
- **tom neutro e limpo**: nada de violência explícita, números de mortos, crimes detalhados, conteúdo sexual ou opinião política. Um acontecimento triste pode aparecer, mas descrito de forma sóbria;
- só fatos que você conseguiu confirmar; se não achar nada bom para um dia, coloque um fato sobre aquela **semana** de 2008, dizendo "This week in 2008, ...".

**O formato:**
```json
{
  "days": {
    "01-01": [ { "text": "...", "src": "nome da página da Wikipedia (em inglês) que confirma" } ],
    "01-02": [ ... ],
    ...
    "12-31": [ ... ]
  },
  "facts": [ { "text": "...", "src": "..." } ]
}
```
- `days`: **as 366 datas** (2008 foi bissexto, então inclua `02-29`), chave `"MM-DD"`, cada uma com **1 a 3 itens**;
- `facts`: **150 fatos** sobre 2008 sem data específica (o que existia, quanto custava, o que era moda, recordes, curiosidades de tecnologia da época: o primeiro iPhone 3G, a App Store, o Android, os netbooks, o 3G, o MySpace contra o Facebook etc.);
- `src`: o título da página da Wikipedia em inglês (ou outra fonte confiável) onde o fato está, para eu conferir alguns por amostragem.

**Exemplos do tom** (só para o estilo; confira as datas antes de usar):
```json
{ "text": "Apple's App Store opens with about 500 apps.", "src": "App Store (Apple)" }
{ "text": "The first Android phone, the T-Mobile G1, is announced.", "src": "HTC Dream" }
```

Se for muita coisa de uma vez, mande um mês por resposta, sempre no mesmo formato (só o pedaço de `days` daquele mês), e os `facts` numa resposta à parte.
